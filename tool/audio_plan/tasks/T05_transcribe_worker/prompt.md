Create tool/transcribe_worker.py and tool/test_transcribe_worker.py following docs/audio-transcription.md if it exists, else this spec. Python 3, stdlib only for the pure functions; faster_whisper imported lazily inside transcribe() only.
Pure functions (tested): escape_markup(s) escapes \ # [ ] $ * _ @ with a backslash; format_ts(seconds)->'MM:SS' (minutes may exceed 59); render_section(segments)->'== Transcript\n\n- MM:SS text\n...' for segments [(start_seconds, text)]; apply_transcript(note_text, segments) replaces an existing '== Transcript' section (until next line starting with '== ' or EOF) or appends it at the end, leaving every other line byte-identical (including '== Comments').
CLI: python tool/transcribe_worker.py --vault DIR --once [--model small] [--lang pt]: for each _system/jobs/transcripts/*.json with status queued: set processing, transcribe vault file job['audio'] with faster-whisper, write apply_transcript into job['note'], set status done and finished_at; on exception set failed and error. Tests (pytest): escape, format_ts (65->'01:05', 3700->'61:40'), render_section, apply_transcript append, replace keeps Comments untouched, and one test that runs the CLI core on a temp vault with transcribe monkeypatched to return fixed segments (status becomes done).
