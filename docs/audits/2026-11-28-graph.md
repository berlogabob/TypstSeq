# Graph audit, 2026-11-28

Read from the code. No tests were run and nothing was measured.
Next step: [graph atlas plan](../plans/2026-11-28-graph-atlas/README.md).

## Summary

The graph has five modes on two unrelated widgets. Focused, Overview, All files and
Timeline share one force-directed `GraphView` and one set of filters. Voronoi is a
separate widget with no edges, no filters and no statuses. The modes do not share
state, colours or names. Two promises in the docs are only half met:

- Thesis rule 3, "the graph can hide or show each source"
  (`docs/thesis/conceptual-model.md:70`): the chips filter note kind, not origin.
- ADR 0002, "the graph and Voronoi draw these statuses": only proposed links are drawn,
  and only around the open note.

## Modes

The mode is a string, `_graphMode`, default `'local'` (`lib/app_mobile.dart:377`). It is
not persisted. The user switches it from an app-bar menu shown only in the graph
(`:3694-3716`). The graph is reached from the More menu (`:2200,2276`). Every mode
except Voronoi is capped at 200 nodes and 500 edges (`boundGraphForLayout`, `:457`).

| Mode (id) | Data | Edges | Layout | Tests |
|---|---|---|---|---|
| Focused (`local`) | 2 hops around the open note or hub, at most 100 nodes | link, tag, citation, proposed link | force, UI thread | unit + widget |
| Overview (`conceptMap`) | tags on 5+ notes, at most 40 nodes and 120 edges | tag co-occurrence on 3+ notes, weighted | force, UI thread | builder unit test |
| All files (`allFiles`) | top 200 nodes by degree | link, tag, citation | force + cluster gravity, UI thread | layout unit tests |
| Timeline (`timeline`) | days + opened articles + notes with `finished`, 45 days | added, read, finished | chronological, O(n) | unit tests |
| Voronoi (`voronoi`) | community → dominant tag → note | none | power-diagram treemap, isolate | 6 widget + 14 core |

Positions are not saved in any mode.

## Defects

### Voronoi

1. Selection highlight does not repaint: `shouldRepaint` ignores `selectedPath`
   (`lib/voronoi_view.dart:840-843`).
2. A layout failure retries forever behind a spinner; there is no error state
   (`:196-199`, `:467`).
3. "In cluster" names the tag, not the cluster, for a note cell (`:539`).
4. "Uncategorized" is not grey although the core says it is (`:620`).
5. Hues differ from All files: `total` counts Uncategorized and "+more"
   (`:237`), and the slot is a running counter
   (`packages/tylog_core/lib/src/voronoi.dart:485-505`).
6. Zoom resets on every index revision, new communities object or resize
   (`:164-171`, `:239`).
7. `buildVoronoiRequest` runs on the UI thread; each child isolate copies the full id
   and label lists (`:280`); every label builds a new `TextPainter` per frame.

### Focused, Overview, All files, Timeline

1. Layout is O(n² · 120 iterations) and runs synchronously in build
   (`lib/graph.dart:222-231`). The isolate branch needs more than 400 nodes, so the cap
   makes it unreachable (`:233-280`). It also skips the unlinked-node shelf and has no
   error handler.
2. Timeline's "added" edge reuses the `link` kind, so the legend calls it "Links"
   (`packages/tylog_core/lib/src/graph.dart:444`). It falls back to the modified time,
   so an edited note looks added that day (`:422-427`).
3. Overview's co-occurrence edge reuses the `tag` kind, so the legend says "Same tag".
   The weight changes layout only and is never drawn.
4. Focused with no note open shows the topic map under the Focused name
   (`lib/app_mobile.dart:454`), without Overview's 40/120 cap.
5. All files is the top 200 nodes by degree. Tag and citation hubs crowd out notes.
   The hairball banner fires only between 181 and 200 nodes (`lib/graph.dart:39,374`).
6. A mutual link is two directed edges: drawn twice, counted twice
   (`packages/tylog_core/lib/src/graph.dart:86-89`).
7. Chips filter after the cap, so hiding a kind does not bring other notes in
   (`lib/graph.dart:350-358`). Hiding a kind leaves its tag hubs behind as orphans.
8. Hit test takes the first node within 30 px, not the nearest (`:766`). Semantics
   rectangles assume the hub radius (`:1671-1687`).
9. SVG export re-runs a plain layout on the UI thread, ignores the timeline layout,
   communities and hidden edges, drops kinds and statuses, and hard-codes two colours
   (`lib/app_mobile/share_flow.dart:105`).
10. Per build: `computeGraphStats`, kind counts, `restrictNoteGraph` and
    `connectionReason` all run again (`lib/graph.dart:343-369,1937`).
11. Dead code: `graphPositions` (`:885`), `GraphPainter.minimumNodeSpacing` (`:1347`),
    `GraphStats.hubPaths`, unused `focalPath` parameters.
12. Labels ignore system text scaling in both widgets.

## How the graph is fed

- Links: the scanner builds `backlinksByTarget`; `buildNoteGraph` inverts it and adds tag
  hubs (tags on 2+ notes) and work hubs.
- Tags that equal a note kind, structural tags and digit-only tags are dropped.
- Communities: label propagation over tag co-occurrence (5+ notes per tag, 3+ shared
  notes per pair, 10 passes, deterministic). Links do not feed it.
- On desktop, once a day, `runClusterStep` writes `_system/clusters/snapshot.json` and
  keeps labels stable. Renames, merges and splits apply only after an accepted decision.
- Cache: `workspace.indexRevision` is the master key. `_graphCache` holds 8 entries keyed
  by revision, suggestions hash, mode, focus and note (`lib/app_mobile.dart:382-438`).
